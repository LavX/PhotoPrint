One file that runs on most 64-bit Linux desktops. No installation, no package manager.

Flatpak

Sandboxed, with the KDE 6.11 runtime. Fits GNOME and KDE systems that already use Flatpak.

Requirements

  • A 64-bit Linux desktop. Fedora 44 is the tested environment.
  • AppImage: FUSE, which most distributions enable by default.
  • ARM64: any Linux distro with the Qt 6 and ImageMagick 7 libraries the README lists.
  • Flatpak: the org.kde.Platform//6.11 runtime from Flathub.
  • Building from source: see the README for the Qt 6.5+, LittleCMS2, CUPS and ImageMagick 7 requirements.
